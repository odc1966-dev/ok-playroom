# 톡톡 팝콘 대소동 — 전체 기획서 (v1.0)

혼자 즐기는 격자 아레나 액션 게임. 컴퓨터 상대와 겨루는 일반 게임 수준의 난이도를 목표로 한다.
이 문서 하나만 읽고 제작할 수 있도록 수치와 규칙을 모두 적었다.

---

## 0. 제작 원칙

1. **오리지널 작품이다.** 기존 상용 게임의 이름, 캐릭터, 맵 이름·배치, 그림, 음악, 효과음을 쓰지 않는다. 장르 규칙(격자, 시한 폭발물, 십자 폭발)만 공유한다.
2. **단일 파일.** `index.html` 하나에 HTML·CSS·JS를 모두 넣는다. 외부 라이브러리, 이미지, 음원 파일 없음.
3. **그림은 코드로 그린다.** Canvas 2D 도형으로 그리고, 소리는 Web Audio로 합성한다.
4. **데이터와 엔진을 분리한다.** 캐릭터·맵·모드·아이템·보스·도전 과제는 모두 데이터 배열이다.
5. **1인용.** 네트워크 기능 없음. 다른 참가자는 전부 컴퓨터가 조종한다.
6. **대상 환경.** Windows PC 크롬·엣지, 키보드. 게임패드와 터치는 보조로 지원한다.

## 1. 세계관과 용어

숲속 동물들이 해마다 여는 "팝콘 축제"에 먼지 도깨비들이 끼어들어 난장판이 된다.

| 용어 | 뜻 |
|---|---|
| 씨앗 | 바닥에 놓는 시한 폭발물(팝콘 씨앗) |
| 팡 | 씨앗이 터지며 십자로 퍼지는 폭발 |
| 상자 | 팡에 깨지는 블록 |
| 바위 | 깨지지 않는 벽 |
| 젤리 | 팡에 맞았을 때 갇히는 상태 |
| 도깨비 | 모험·버티기에 나오는 일반 적 |
| 라이벌 | 플레이어와 같은 규칙으로 움직이는 컴퓨터 상대 |

## 2. 화면 구성

### 2.1 해상도

- 논리 해상도 960×720(4:3). 창 크기에 맞춰 비율을 유지하며 확대·축소한다.
- 경기장: 15칸×13칸, 칸 크기 48px → 720×624. 화면 왼쪽 아래에 붙인다.
- 위쪽 띠(960×96): 남은 시간, 모드 이름, 목표 진행도.
- 오른쪽 판(240×624): 참가자 목록(초상, 상태, 처치 수), 내 능력치(씨앗·범위·속도), 보유 아이템 칸 2개, 특수기 쿨타임.

### 2.2 화면 흐름

```
타이틀 → 메인 메뉴 ┬ 모험 → 월드 지도 → 스테이지 → 결과
                   ├ 대전(개인전/팀전/깃발 뺏기) → 방 설정 → 캐릭터 선택 → 경기 → 결과
                   ├ 랭크전 → 캐릭터 선택 → 경기 → 결과(점수 변동)
                   ├ 도전(버티기/보스 러시/시간 도전/생각 퍼즐/오늘의 도전)
                   ├ 도감(캐릭터/아이템/도깨비/보스)
                   ├ 기록(전적/도전 과제/최고 기록)
                   └ 설정(소리/조작/화면/저장 초기화)
```

- 경기 중 Esc: 일시정지(계속 / 다시 시작 / 나가기). 랭크전은 나가면 패배 처리.
- 모든 메뉴는 방향키+Enter+Esc만으로 조작할 수 있어야 한다. 마우스도 된다.

### 2.3 방 설정(대전)

맵(무작위 포함), 참가자 수(2~8), 라이벌 지능(1~5 또는 섞기), 경기 시간(2/3/5분), 승리 조건(1판 / 3판 2선승 / 5판 3선승), 아이템 양(적게/보통/많이), 서든데스(켜기/끄기).

## 4. 핵심 시스템

### 4.1 시간과 좌표

- 고정 간격 갱신 60Hz(1틱 = 1/60초). 그리기는 보간한다.
- 위치는 칸 단위 실수(예: x=3.5는 3번 칸의 중앙). 캐릭터 충돌 상자는 0.7×0.7칸.

### 4.2 이동

- 속도 단계 s(1~9) → 초당 `2.0 + 0.5×s` 칸. (단계 5 = 4.5칸/초, 단계 9 = 6.5칸/초)
- **코너 보정:** 벽에 막혔을 때 칸 중앙에서 0.35칸 이내로 어긋나 있으면, 진행 방향의 옆 칸이 비어 있는 쪽으로 자동으로 밀어 준다. 이 게임 조작감의 핵심이므로 반드시 구현한다.
- 자기가 방금 놓은 씨앗 위에서는 벗어날 때까지 통과할 수 있다. 벗어난 뒤에는 벽처럼 막힌다.
- 다른 캐릭터와는 서로 통과한다.

### 4.3 씨앗과 팡

| 항목 | 값 |
|---|---|
| 도화선 | 2.5초 |
| 팡 유지 | 0.45초 |
| 범위 | 중심 + 네 방향으로 범위 단계만큼의 칸 |
| 차단 | 바위에서 멈춤. 상자는 깨뜨리고 그 칸에서 멈춤 |
| 연쇄 | 팡이 다른 씨앗에 닿으면 0.05초 뒤 그 씨앗도 터짐 |
| 아이템 | 바닥에 놓인 아이템이 팡에 닿으면 사라짐(상자에서 막 나온 0.5초 동안은 보호) |
| 동시 보유 | 씨앗 단계만큼만 동시에 놓을 수 있음. 터지면 회수 |

- 씨앗은 칸 중앙에만 놓인다(캐릭터 중심이 속한 칸). 이미 씨앗이 있는 칸에는 못 놓는다.
- 터지기 0.6초 전부터 씨앗이 빠르게 부풀며 예고한다.

### 4.4 젤리(갇힘)와 탈락

1. 팡에 닿으면 젤리에 갇힌다. 이동 속도가 0.5칸/초로 떨어지고 씨앗·아이템(바늘 제외)·특수기를 쓸 수 없다.
2. 5초가 지나면 탈락한다.
3. 갇힌 동안 적(라이벌, 도깨비)이 닿으면 즉시 탈락하고 그 적이 처치 점수를 얻는다.
4. 같은 편이 닿으면 풀려난다(팀전·깃발 뺏기).
5. 바늘을 쓰면 풀려나고 1.5초간 무적이다.
6. 갇힌 상태에서 팡을 또 맞아도 변화 없다.
7. 탈것을 타고 있으면 갇히지 않고 탈것만 잃으며 1초간 무적이다.

### 4.5 서든데스

경기 시간이 1분 남으면 바깥 테두리부터 소용돌이 순서로 0.35초마다 한 칸씩 바위가 떨어진다. 떨어질 칸은 1초 전에 그림자로 예고한다. 바위에 깔리면 즉시 탈락한다. 가운데 3×3칸은 남긴다.

### 4.6 승패

- 개인전: 마지막 1명. 시간이 끝나면 처치 수 → 깬 상자 수 순으로 판정, 그래도 같으면 무승부.
- 모드별 조건은 9장 참고.

## 7. 맵 10종

공통: 15×13, 테두리는 바위. 짝수 행·짝수 열 교차점에 바위 기둥을 두는 것이 기본 골격이다(맵별로 변형). 시작 지점은 8곳이며 각 시작 지점과 인접 2칸은 항상 비운다. 상자 배치는 좌우 대칭을 기본으로 하고 매판 15%가 무작위로 바뀐다.

## 9. 모드 10종

### 9.1 모험

- 하트 3개. 탈락하면 하트 1개를 잃고 그 스테이지를 다시 한다. 하트가 0이면 그 월드 1스테이지로 돌아간다.

- 전체 클리어 후 "어려움" 난이도가 열린다(도깨비 속도 ×1.25, 라이벌 지능 +1, 하트 1개).

### 9.2 개인전

2~8명, 마지막 1명이 승리. 방 설정은 2.3 참고.

### 9.3 팀전

2:2, 3:3, 4:4. 같은 편의 팡에도 갇힌다(아군 피해 있음). 같은 편이 닿으면 풀려난다. 한 팀이 전원 탈락하면 끝난다. 컴퓨터 동료에게 F1~F3으로 지시할 수 있다(따라와 / 공격해 / 구해 줘).

### 9.4 랭크전

- 4명 개인전, 맵 무작위, 3분, 서든데스 켜짐.
- 등급: 씨앗 → 새싹 → 꽃 → 열매 → 나무 → 숲 → 전설. 각 등급 3단계(전설 제외), 단계당 100점.
- 점수: 1등 +30, 2등 +10, 3등 -10, 4등 -25. 처치 1회당 +3(최대 +9).
- 라이벌 지능은 등급에 따른다.

| 등급 | 라이벌 지능 구성(3명) |
|---|---|
| 씨앗 | 1, 1, 2 |
| 새싹 | 2, 2, 2 |
| 꽃 | 2, 3, 3 |
| 열매 | 3, 3, 4 |
| 나무 | 4, 4, 4 |
| 숲 | 4, 5, 5 |
| 전설 | 5, 5, 5 (능력치 1단계씩 높게 시작) |

### 9.5 버티기

- 한 맵에서 끝없이 이어지는 무리. 하트 3개.
- n번째 무리: 도깨비 `3 + n`마리(최대 16), 5의 배수 무리에 중간 보스(두꺼비 체력 6, 속도 2.5).
- 무리를 넘길 때마다 상자가 30% 다시 생긴다.
- 10무리마다 강화 3개 중 1개 선택: 하트 +1 / 능력치 최대치 +1 / 특수기 쿨타임 -20% / 시작 시 방패 / 아이템 확률 +10% / 젤리 시간 +2초.
- 기록: 도달 무리 수.

### 9.6 보스 러시

보스 10종을 연속으로 상대한다. 하트 3개가 이어지고, 보스를 쓰러뜨릴 때마다 아이템 3개 중 1개를 고른다. 기록: 클리어 시간.

### 9.7 시간 도전

맵마다 고정 배치(무작위 없음). 상자 전부 깨기 + 도깨비 6마리 쓰러뜨리기의 최단 시간을 겨룬다. 금·은·동 기준 시간이 있다. 내 최고 기록의 "유령"이 반투명으로 함께 달린다.

### 9.8 깃발 뺏기

3:3. 상대 진영 깃발을 집어 우리 진영으로 가져오면 1점. 깃발을 든 채 갇히면 그 자리에 떨어뜨린다. 탈락하면 5초 뒤 진영에서 부활한다. 5분 또는 3점 선취. 맵은 좌우 대칭인 1·2·5·8·10번만 쓴다.

### 9.9 생각 퍼즐

50문제. 시간 제한 없음, 되돌리기(한 수 전) 무제한, 다시 시작 가능.

| 유형 | 문제 수 | 내용 |
|---|---|---|
| 연쇄 | 10 | 씨앗 n개로 모든 상자 깨기 |
| 밀기 | 10 | 장갑으로 씨앗을 굴려 닿지 않는 표적 맞히기 |
| 탈출 | 10 | 제한된 씨앗으로 출구까지 길 내기(자기 팡에 맞으면 실패) |
| 타이밍 | 10 | 움직이는 도깨비를 정해진 수 안에 잡기 |
| 장치 | 10 | 순간이동 문·얼음·스위치를 이용 |

- 문제는 문자 격자로 정의한다. 각 문제에 **정답 입력 순서**를 함께 저장하고, 개발용 자동 검증 함수가 정답을 재생해 풀리는지 확인한다. 검증에 실패한 문제는 싣지 않는다.
- 평가: 최소 수로 풀면 별 3개.

### 9.10 오늘의 도전

날짜를 씨앗값으로 맵·캐릭터·규칙을 고정한다. 하루 한 번 기록이 남고 다시 하기는 연습 취급이다.

특수 규칙 14종: 전원 범위 최대 / 전원 속도 최대 / 도화선 1.5초 / 도화선 4초 / 아이템 없음 / 함정 아이템만 / 처음부터 서든데스 / 전원 리모컨 / 전원 투명(3초마다 깜빡 보임) / 상자가 20초마다 다시 생김 / 씨앗 무한 / 한 방 탈락(젤리 없음) / 거울 조작 / 탈것 축제.

## 10. 컴퓨터 상대(라이벌) 설계

### 10.1 정보 구조

매 틱 갱신하는 **위험 지도**: 각 칸에 "몇 초 뒤 팡이 지나가는가"를 기록한다(연쇄를 반영해 가장 이른 시각으로). 맵 장치(분출구, 기차, 프레스, 서든데스 바위)도 같은 지도에 넣는다.

### 10.2 판단 순서(우선순위)

1. **도망:** 현재 칸이 위험하면, 팡 도달 전에 닿을 수 있는 가장 가까운 안전 칸으로 간다(너비 우선 탐색, 이동 시간과 위험 시각을 비교).
2. **마무리:** 갇힌 적이 닿을 수 있는 거리에 있으면 가서 터뜨린다.
3. **구출:** 갇힌 같은 편에게 간다(팀전).
4. **공격:** 적의 퇴로를 계산해, 씨앗을 놓으면 적이 안전 칸에 못 닿는 자리를 찾으면 놓는다(가두기).
5. **수집:** 가까운 아이템으로 간다(함정 아이템은 지능 3 이상이 피함).
6. **파괴:** 상자를 가장 많이 깰 수 있는 자리에 씨앗을 놓는다.
7. **배회:** 적 쪽으로 이동한다.

씨앗을 놓기 전에는 반드시 "놓은 뒤 내가 도망칠 수 있는가"를 모의 계산한다. 지능 단계에 따라 이 검사를 일부러 틀리게 한다.

### 10.3 지능 5단계

|---|---|---|---|---|---|
| 반응 지연 | 0.50초 | 0.35초 | 0.22초 | 0.15초 | 0.10초 |
| 판단 주기 | 0.50초 | 0.35초 | 0.25초 | 0.15초 | 0.10초 |

| 성향 | 특징 |
|---|---|
| 공격형 | 공격 우선순위를 수집보다 위에 둠. 능력치가 낮아도 싸움을 검 |

## 12. 화면 표시(HUD)와 피드백

- 참가자 머리 위: 이름표(나는 노란 화살표). 갇힌 참가자는 남은 시간 고리 표시.
- 내 씨앗은 테두리 색으로 구분한다.
- 특수기: 쿨타임 원형 게이지, 준비되면 짧게 빛남.
- 경기 시작: "3, 2, 1, 팡!" 카운트. 그동안 조작 불가.
- 결과 화면: 순위, 처치, 깬 상자, 획득 아이템, 얻은 경험치, 도전 과제 진행.

## 13. 그림과 소리

### 13.1 그림

- 둥글고 선이 굵은 만화풍. 칸 테두리는 옅게.
- 맵별 색조: 1 연두 / 2 분홍 / 3 하늘 / 4 보라 / 5 흰색·금색 / 6 갈색·회색 / 7 주황 / 8 원색 혼합 / 9 빨강·검정 / 10 남색·은색.
- 효과: 팡(중심에서 퍼지는 팝콘 알갱이 입자), 상자 파편, 아이템 반짝임, 발자국 먼지.
- 화면 흔들림: 연쇄 3개 이상과 보스 공격에만, 0.15초. 설정에서 끌 수 있다.
- 경기 종료 시 0.5초 느린 화면.

### 13.2 소리(Web Audio 합성)

| 종류 | 내용 |
|---|---|
| 효과음 | 씨앗 놓기, 팡(연쇄 수에 따라 음정 상승), 상자 깨짐, 아이템 획득(종류별 3음), 갇힘, 탈출, 탈락, 특수기, 예고음, 메뉴 이동·선택 |
| 배경음 | 맵별 8~16마디 반복 선율. 사각파·삼각파 2성부 + 잡음 타악. 남은 시간 30초부터 빠르기 1.2배 |
| 음량 | 효과음·배경음 따로 조절. 첫 입력 전에는 소리를 내지 않는다(브라우저 정책) |

## 14. 기술 구조

### 14.1 코드 구성(파일은 하나, 구역으로 나눔)

```
1. 상수·데이터   CHARACTERS, ITEMS, MAPS, MODES, ENEMIES, BOSSES, PUZZLES, ACHIEVEMENTS
2. 유틸          난수(씨앗값 지정 가능), 격자 함수, 너비 우선 탐색
3. 입력          키보드·게임패드·터치를 하나의 "행동" 상태로 통합
4. 세계          Grid, Entity(Player, Enemy, Boss, Seed, Blast, Item), 맵 장치
5. 규칙          모드별 시작·갱신·종료 판정 객체
6. 인공지능      위험 지도, 라이벌 판단, 도깨비 행동
7. 그리기        카메라 없음, 층 순서: 바닥→장치→아이템→씨앗→캐릭터→팡→효과→HUD
8. 소리          합성기, 배경음 순서기
9. 화면          화면 상태 기계(타이틀, 메뉴, 선택, 경기, 결과, 도감, 기록, 설정)
10. 저장         불러오기·저장·버전 이전
11. 개발 도구    자동 대전, 퍼즐 검증, 성능 표시(F9)
```

### 14.2 규칙

- 경기 로직은 **고정 틱 + 지정 가능한 난수**로 결정적이어야 한다. 같은 씨앗값과 입력이면 결과가 같다(시간 도전 유령, 자동 대전 검증에 필요).
- 로직과 그리기를 분리한다. 그리기를 끄고 로직만 빠르게 돌릴 수 있어야 한다.
- 맵은 문자 격자로 정의한다. 예: `#` 바위, `.` 빈칸, `B` 상자, `?` 무작위(밀도에 따라), `S` 시작 지점, 그 밖은 맵별 장치 기호.
- 주소 뒤에 `?dev=1`을 붙이면 개발 도구가 켜진다.

### 14.3 성능 기준

참가자 8명, 씨앗 40개, 입자 300개에서 초당 60프레임. 틱당 인공지능 계산 총합 4ms 이내(라이벌마다 판단 시점을 엇갈리게 배치).

## 15. 제작 단계

한 번에 다 만들지 않는다. 단계마다 직접 플레이해 확인한 뒤 다음으로 넘어간다.

| 단계 | 만들 것 | 완료 기준 |
|---|---|---|
| 1 | 격자, 이동(코너 보정), 씨앗, 팡, 연쇄, 상자, 능력 아이템 3종, 젤리·탈락, 도토리 마을, 토리 | 혼자 돌아다니며 상자를 깨고 자기 팡에 갇혀 탈락까지 된다. 좁은 길에서 걸림 없이 돈다 |
| 2 | 위험 지도, 라이벌 지능 5단계와 성향, 개인전, 서든데스, 결과 화면, 자동 대전 도구 | 자동 대전 100판 무오류. 지능 5가 지능 1을 90% 이상 이긴다. 지능 3과 해 보면 긴장감이 있다 |
| 3 | 아이템 전체, 캐릭터 10종과 특수기 | 모든 아이템·특수기가 표대로 동작. 라이벌이 지능에 맞게 사용 |
| 4 | 맵 10종과 장치 | 맵마다 자동 대전 50판 무오류. 라이벌이 장치에 어이없이 당하지 않는다(지능 2 이상) |
| 5 | 도깨비 10종, 보스 10종, 모험 50스테이지 | 1-1부터 10-5까지 클리어 가능. 별 평가 저장 |
| 6 | 팀전, 깃발 뺏기, 랭크전, 버티기, 보스 러시, 시간 도전, 오늘의 도전 | 각 모드가 시작부터 결과까지 돈다 |
| 7 | 생각 퍼즐 50문제와 검증 도구 | 50문제 모두 정답 재생 검증 통과 |
| 8 | 성장(레벨, 도전 과제, 해금), 기록·도감 화면, 저장 내보내기 | 도전 과제 40개가 조건대로 달성된다 |
| 9 | 그림 다듬기, 소리, 연출, 게임패드·터치, 키 설정 | 14.3 성능 기준 충족 |
| 10 | 밸런스 조정 | 16장 기준 충족 |

### 단계별 지시문 틀

```
docs/popcorn-gdd.md를 읽고 15장의 [n]단계만 구현해라.
이전 단계의 동작을 깨뜨리지 마라.
끝나면 ?dev=1 자동 대전(또는 해당 검증 도구)을 돌려 완료 기준을 확인하고,
브라우저에서 실제 화면을 띄워 확인한 결과를 보고해라.
기획서와 다르게 구현한 부분이 있으면 목록으로 알려라.
```

## 16. 밸런스 기준

자동 대전으로 측정한다(지능 4끼리, 4명 개인전, 맵 무작위, 캐릭터당 500판 이상).

| 항목 | 목표 |
|---|---|
| 캐릭터별 승률 | 20~30%(기대값 25%) |
| 평균 경기 시간 | 1분 40초 ~ 2분 40초 |
| 서든데스 도달 비율 | 15~35% |
| 자기 씨앗 탈락 비율(지능 4) | 10% 이하 |
| 시작 지점별 승률 차이 | 5%p 이내 |
| 무승부 비율 | 3% 이하 |

벗어나면 캐릭터 능력치·쿨타임 → 아이템 가중치 → 맵 배치 순으로 조정한다. 사람이 느끼는 난이도는 자동 대전으로 알 수 없으므로 10단계에서 직접 플레이하며 지능 단계별 수치를 다듬는다.

## 17. 확정하지 않은 것

- 캐릭터·도깨비·보스의 구체적인 생김새는 6장·8장의 지침 범위에서 제작 단계에 정한다.
- 퍼즐 50문제의 실제 배치는 7단계에서 만들고 검증 도구로 거른다.
- 맵의 정확한 문자 격자는 7장의 골격·밀도·장치 수에 맞춰 4단계에서 만든다.
- 이 문서의 수치는 플레이 검증 전의 초기값이다.
